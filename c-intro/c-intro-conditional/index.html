如果…（if）

我們生活中很多時候會依照不同情況做不同的決定，例如我們說

如果明天早上下雨了，我就帶雨傘出門。

這裡我們可以看到，「下雨」是我們的「條件」，而有沒有帶雨傘則是條件滿足或不滿足所帶來的結果。

註：在 C 語言中，條件判斷其實是看「運算結果是否為 0」：0 代表 false，非 0 代表 true。如果想在程式碼裡直接寫 true 或 false，則需要引入 stdbool.h。
